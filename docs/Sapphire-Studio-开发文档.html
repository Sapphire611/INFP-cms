📖一、项目概述

Sapphire Studio 是一个 AI 工作站，提供流式 AI 对话、Tool Calling（天气/时间/计算/联网搜索）、Markdown 富文本渲染。

1.1 技术栈

类别技术
框架Next.js 15 (App Router)
数据库Supabase (PostgreSQL)
UIShadcn UI + Radix UI + Tailwind CSS
状态管理Zustand (vanilla) + React Query
AI SDKVercel AI SDK v7 (ai + @ai-sdk/openai)
模型DeepSeek (deepseek-v4-flash，8192 tokens)
Markdownreact-markdown + remark-gfm

🔌五、模型接入

文件：src/lib/ai-client.ts

import { createOpenAI } from "@ai-sdk/openai";

// 懒加载：模块导入时不立即初始化（key 缺失不会炸）
let _deepseek = null;
function getClient() {
  if (!_deepseek) {
    const key = process.env.DEEPSEEK_API_KEY;
    if (!key) throw new Error("DEEPSEEK_API_KEY 未配置");
    _deepseek = createOpenAI({ apiKey: key, baseURL: "https://api.deepseek.com/v1" });
  }
  return _deepseek;
}
// Proxy 代理：属性访问时懒加载
export const deepseek = new Proxy({}, { get(_, p) { return getClient()[p]; } });
export const CHAT_MODEL = "deepseek-v4-flash";
模型状态说明
deepseek-v4-flash当前默认，8192 tokens
deepseek-v4-pro待启用特定功能需要更强推理时升级
deepseek-chat2026/07/24 弃用已全部替换

🧰六、AI 工具集

文件：src/services/chatTools.ts。四个工具均在服务端执行，失败时 throw error（AI SDK 发 tool-error 事件，UI 显示红标❌）。

工具数据源Key说明
webSearchBing → DuckDuckGo免费 Bing 优先（cn.bing.com 国内直连），三层降级解析。
失败时自动回退 DuckDuckGo。10s 超时。
getWeatherwttr.in免费全球城市天气，JSON API。8s 超时。
getCurrentTimeIntl.DateTimeFormat内置支持时区参数，默认 Asia/Shanghai。
calculate沙箱 new Function()内置Math 函数白名单，无全局访问。

Bing 搜索三层降级

  1. 解析 li.b_algo 块（标准桌面版结构）
  2. 通用链接提取（过滤 bing/microsoft 自身链接，>5 字文本）
  3. 换 cn.bing.com 再试一次
全部免费，零 API Key。只要配好 DEEPSEEK_API_KEY，AI 系统即用。

🌊七、流式数据流

POST /api/chat │ ├─ 1. saveUserMessage(conversationId, userMessage) — fire-and-forget │ └─ ReadableStream.start() │ ├─ streamText({ model, system, messages, tools }) │ │ │ ├─ text-delta → SSE { type: "text", content } │ ├─ tool-call → SSE { type: "tool-call", toolCallId, toolName, args } │ ├─ tool-result→ SSE { type: "tool-result", toolCallId, toolName, result } │ ├─ tool-error → SSE { type: "tool-error", toolCallId, toolName, error } │ └─ finish → SSE { type: "done", finishReason } │ ├─ 如果 assistantContent 为空 → forced reply (generateText 补发) ├─ saveAssistantMessage() → Supabase ├─ controller.close() ├─ generateAndSaveTitle() → generateText() → Supabase └─ updateConversationTimestamp() + summarization check Client (chat-store.ts): ├─ SSE 事件消费 → 更新 currentMessages state ├─ isSending=false → 移动对话到列表顶部 └─ 5s 后 loadConversations() 取回服务器生成的标题

SSE 事件类型

事件载荷
text{ content: string } — 流式文字增量
tool-call{ toolCallId, toolName, args } — AI 发起工具调用
tool-result{ toolCallId, toolName, result } — 工具执行成功
tool-error{ toolCallId, toolName, error } — 工具执行失败
done{ finishReason } — 流结束
error{ error: string } — 流异常

🗄️八、状态管理

使用 Zustand vanilla store，通过 React Context 注入。四种加载状态各自独立，互不干扰：

状态谁设置影响范围
isLoadingloadConversations()侧栏 loading spinner
isCreatingcreateConversation()"新对话"按钮 disabled + spinner
isDeletingdeleteConversation()"新对话"按钮 disabled（防并发）
isSendingsendMessage()输入框 disabled + "AI正在思考..."
isLoadingMessagesloadMessages()聊天区 loading，阻止切换对话

消息存储

表内容
conversations对话元数据：id, user_id, title, model, agent_id, 时间戳
messages消息：id, conversation_id, role, content, tool_calls (JSONB), created_at
conversation_summaries摘要：id, conversation_id, summary_text, message_count
消息存储在 Supabase，dev/prod 共用同一数据库时自动同步。

✏️九、标题生成

自动生成：首次对话流结束后，调用 generateText()（共享 deepseek 客户端）根据用户问题生成 5-20 字标题，存入 Supabase。客户端 5 秒后 loadConversations() 拿到。

兜底：API 失败时用用户问题前 20 字。确保标题不会是"新对话"。

手动编辑：hover 对话项时标题右边出现 ✏️ 图标，点击 inline 编辑，Enter 保存 / Escape 取消，PATCH /api/chat/conversations/[id] 持久化。

Forced Reply

流结束后如果 assistantContent 太短（< 30 字符）且有 tool 调用，自动调 generateText 补一发完整回答，确保用户不会看到空白或残缺回复。

📐十一、开发模式

添加新 Tool

  1. 在 src/services/chatTools.ts 用 tool({...}) 定义
  2. 加入 chatTools 导出
  3. 更新 system prompt（src/config/agents.ts）

添加新 API 路由

  1. 在 src/app/api/ 创建路由
  2. 用 requireAuth() 保护
  3. Zod 校验 + 统一 JSON 响应

数据库规范

  • 始终通过 service 层操作，不直接调 Supabase
  • supabase-admin 仅在需要绕过 RLS 时使用
  • DB 字段 snake_case，TS 接口 camelCase
