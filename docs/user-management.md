# 用户管理技能

帮我管理 INFP-CMS 系统的用户。

## 可用操作

### 1. 列出所有用户
显示系统中所有用户的列表，包括邮箱、用户名、类型和状态。

### 2. 重置用户密码
为指定用户重置密码。系统会自动进行双重加密（SHA-256 + bcrypt）。

**参数**:
- 用户邮箱（必填）
- 新密码（必填）

### 3. 创建新用户
创建一个新的管理员或普通用户账户。

**参数**:
- 邮箱（必填）
- 密码（必填）
- 用户类型（admin 或 user，默认 user）
- 用户名（可选，默认使用邮箱前缀）

### 4. 启用/禁用用户
启用或禁用指定用户的账户。

**参数**:
- 用户邮箱（必填）
- 操作（enable 或 disable）

### 5. 查看用户统计
显示用户总数、活跃用户数、管理员数量等统计信息。

## 注意事项

- 所有密码都会进行 SHA-256 + bcrypt 双重加密
- 重置密码操作不可逆，请谨慎操作
- 禁用用户后，该用户无法登录系统
- 创建用户时会自动检查邮箱和用户名是否已存在

## 执行流程

1. 确认操作类型和参数
2. 验证参数有效性
3. 执行相应操作
4. 显示操作结果
