# 密码管理技能

帮助处理 INFP-CMS 系统中的密码相关问题。

## 可用操作

### 1. 生成密码 Hash
为指定的明文密码生成正确的双重加密 hash（SHA-256 + bcrypt）。

**参数**:
- 明文密码（必填）

**使用场景**:
- 需要直接在数据库中更新密码时
- 批量创建用户时
- 测试密码功能时

**输出**:
- SHA-256 hash（前端发送的）
- Bcrypt hash（存储在数据库的）
- SQL 更新语句

### 2. 重置用户密码
为指定用户重置密码。

**参数**:
- 用户邮箱（必填）
- 新密码（必填）

### 3. 批量重置密码
为多个用户批量重置密码（谨慎使用）。

**参数**:
- 用户邮箱列表（必填）
- 新密码（必填）

**警告**: 此操作会影响多个用户，请确认后执行。

### 4. 密码策略检查
检查密码是否符合安全策略。

**当前策略**:
- 最小长度：6个字符
- 建议包含：大小写字母、数字、特殊字符

### 5. 验证密码格式
验证给定的字符串是否是有效的 SHA-256 hash（64位十六进制字符串）。

## 加密说明

本系统使用双重加密：

```
明文密码 (123456)
    ↓
SHA-256 + 固定 Salt
    ↓
b2d520cc77033dcfca7748d3bb6b3f4ea4c80f89ea2f2f50cb03d431961c7939
    ↓
Bcrypt (强度 10)
    ↓
$2b$10$UXGQfMO4pZoXvbVHigrN/uTPYpP32osVgQYKA.0Wt.JFIjuyqNBzq
```

**为什么这样设计？**
- 传输安全：网络中传输的是 SHA-256 hash
- 存储安全：数据库存储的是 bcrypt hash
- 双重保护：即使获取其中一层，也无法反推原始密码

## 注意事项

- 密码重置操作不可逆
- 生成密码 hash 时会使用 `.env` 中配置的 `NEXT_PUBLIC_PASSWORD_SALT`
- 确保在生产环境中使用强随机 salt
