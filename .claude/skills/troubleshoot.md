# 问题排查技能

帮助诊断和解决 INFP-CMS 系统中的各种问题。

## 可用操作

### 1. 诊断登录问题
诊断用户无法登录的原因。

**检查项目**:
- 用户账户是否存在
- 账户是否被禁用
- 密码格式是否正确（新格式 vs 旧格式）
- Cookie 设置是否正确
- JWT Token 是否有效
- 网络请求是否成功

**常见问题**:
- 密码错误
- 账户未激活
- Cookie 被浏览器阻止
- 环境变量配置错误

### 2. 诊断数据库连接问题
检查 Supabase 数据库连接状态。

**检查项目**:
- 环境变量配置
- 数据库可达性
- 连接池状态
- 权限配置
- 表结构完整性

**测试命令**:
- 访问 `/api/health` 端点
- 检查 Supabase Dashboard 状态
- 验证连接字符串

### 3. 诊断构建错误
诊断项目构建失败的原因。

**检查项目**:
- TypeScript 编译错误
- ESLint 错误
- 依赖问题
- 环境变量缺失
- 内存不足

**解决步骤**:
1. 查看完整错误日志
2. 本地复现问题
3. 检查依赖版本
4. 清理缓存重新构建

### 4. 诊断密码加密问题
诊断密码相关的加密问题。

**检查项目**:
- 前端 SHA-256 加密是否正常
- 后端 bcrypt 加���是否正常
- 密码格式是否正确
- Salt 配置是否正确
- 数据库密码字段格式

**常见错误**:
- 直接存储 SHA-256 hash 到数据库
- 忘记配置 `NEXT_PUBLIC_PASSWORD_SALT`
- 使用了不同的 salt
- 密码字段格式不匹配

### 5. 诊断 API 问题
诊断 API 路由相关的问题。

**检查项目**:
- 路由是否正确注册
- 请求方法是否正确
- 参数格式是否正确
- 响应格式是否正确
- 错误处理是否完善

**测试方法**:
- 使用 curl 测试端点
- 检查浏览器 Network 面板
- 查看 Vercel 函数日志

### 6. 检查系统健康
全面检查系统健康状态。

**检查项目**:
- 数据库连接状态
- API 端点响应
- 用户登录功能
- 环境变量配置
- 部署状态

**生成健康报告**:
- 总体状态（正常/警告/错误）
- 详细问题描述
- 建议的解决方案

## 常见错误及解决方案

### 错误: "Invalid credentials"
**原因**: 用户名或密码错误
**解决**:
1. 检查邮箱是否正确
2. 重置密码
3. 确认账户已激活

### 错误: "Database connection failed"
**原因**: 数据库连接失败
**解决**:
1. 检查 `DATABASE_URL` 环境变量
2. 验证 Supabase 凭据
3. 检查网络连接

### 错误: "JWT_SECRET is not defined"
**原因**: JWT 密钥未配置
**解决**:
1. 在 `.env` 中添加 `JWT_SECRET`
2. 在 Vercel 中配置环境变量
3. 重启应用

### 错误: "User is not active"
**原因**: 用户账户被禁用
**解决**:
1. 联系管理员启用账户
2. 检查 `users` 表的 `is_active` 字段

### 错误: "Cannot find module '@/lib/xxx'"
**原因**: 模块路径错误
**解决**:
1. 检查 `tsconfig.json` 配置
2. 验证文件路径
3. 重新安装依赖

3. **使用 TypeScript 严格模式**
